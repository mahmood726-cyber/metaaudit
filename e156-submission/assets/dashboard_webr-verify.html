What this page does: It runs metafor::rma() entirely in your browser via WebR — no server, no uploads, no network calls after initial load. The R results are compared side-by-side against MetaAudit's Python engine on 5 representative datasets spanning binary and continuous outcomes.

Why small differences are expected: MetaAudit uses a Fisher-scoring REML iteration (Paule-Mandel warm start) while metafor uses its own REML implementation with potentially different convergence criteria. For datasets where tau² = 0 (homogeneous), both engines should agree within 0.001. For high-heterogeneity datasets, tau² estimates may differ slightly. CIs shown here use HKSJ adjustment with t-distribution, while metafor defaults to normal-theory CIs — this explains most CI differences.
