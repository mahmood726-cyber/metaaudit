About MetaAudit

MetaAudit is a computational quality audit of 6,229 meta-analyses from 501 Cochrane systematic reviews, applying 11 automated detection modules to each analysis. No external dependencies — all data is embedded in this file.

Detection Modules

  • Prediction Gap — Prediction interval extends substantially into the opposite direction from the point estimate
  • Model Misspecification — Detected via I²/tau² profile diagnostics
  • Fragility — Fragility index indicates result is dependent on very few events
  • Underpowered — Inadequate power even assuming the pooled effect size
  • Publication Bias — Egger test / trim-and-fill / funnel asymmetry
  • Small-Study Effects — Systematic difference between small and large studies
  • Excess Significance — Unusually high proportion of significant results (Ioannidis & Trikalinos method)
  • Integrity — Internal consistency of reported statistics
  • Overlap — Possible duplicate participants across included studies
  • Overclaiming — Abstract conclusions overstated relative to results
  • Certainty Mismatch — GRADE certainty rating inconsistent with pooled effect size

Severity Levels

  • PASS — No issue detected
  • WARN — Possible concern; warrants manual review
  • FAIL — Clear methodological concern flagged
  • CRITICAL — Severe flaw that may invalidate conclusions
  • INSUFF — Insufficient data to evaluate the module

Data Source

All meta-analyses sourced from the Cochrane Library (open-access reviews only). Data retrieved January 2025. No patient-level data used. All computations are rule-based and deterministic given fixed inputs.

AI Disclosure

The detection modules use rule-based statistical algorithms, not large language models. Dashboard interface was assisted by Claude (Anthropic, 2025). All statistical computations are auditable and reproducible given the source data.
